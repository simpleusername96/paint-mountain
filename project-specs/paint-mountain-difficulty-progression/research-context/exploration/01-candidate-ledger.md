# Candidate Ledger

## Purpose

Freeze exactly five new concepts before evaluation.

## Sources

- `../00-intake.md`
- `../research/01-local-product-truth.md`

## Findings

The exploration deliberately used five distant-domain lenses rather than five
variations of harder terrain:

| Lens outside the game genre | Translated design question |
| --- | --- |
| Temporary construction and billiard cushions | Can an earlier object become infrastructure for later work? |
| Relay races and production scheduling | Can arrival order matter more than one isolated action? |
| Expedition fuel planning and portfolio allocation | How should one finite reserve be divided across several commitments? |
| Constraint optimization and binding contracts | How does an early commitment reshape later choices? |
| Irrigation districts and emergency-service coverage | How should limited actions be assigned across separated regions? |

### N1 — Resident Ball Bumpers

Earlier balls deliberately settle in terrain pockets and become collision
bumpers for later root launches. Difficulty grows from one obvious placement to
multi-ball constructions. It makes persistent world state strategic but needs
projectile-projectile collision and strict stability/capacity validation.

### N2 — Two-Shot Relay

The player launches a second root while the first is active so arrival order
interacts with mechanism charges and cooldowns. Difficulty grows from generous
windows to multi-mechanism timing. It reuses current concurrency but risks
turning a planning puzzle into a reflex test.

### N3 — Shared Propellant

All accepted root launches draw their selected power from one stage budget.
Difficulty grows by lowering average allowance while preserving the option to
spend 100 on a chosen launch. It deepens an existing choice with low physics
risk and a clear feasibility test.

### N4 — Aim-Axis Lock

After the first launch, one aim parameter remains fixed for the stage. Difficulty
grows from a known power lock to player-selected commitment. It is technically
small but removes experimentation and makes early mistakes disproportionately
expensive.

### N5 — Target Archipelago

One authoritative target mask contains multiple separated visible regions.
Difficulty grows from two large nearby regions to several unequal regions that
need distinct launch roles. It is readable and preserves one score, but can
become checklist work and demands careful target-boundary presentation.

## Limitations

- These are product hypotheses, not implemented or playtested features.
