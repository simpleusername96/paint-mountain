## Findings

### Status

- Created: 2026-08-13
- Requested artifact: broad staged ideas, comparative analysis, one selected
  direction, an implementation plan, and a plain-language Korean Markdown
  explanation.
- Intended use: decide the next coherent difficulty-progression implementation.
- Scope and time horizon: the existing thirty-stage vertical slice and its next
  implementation cycle.
- Novelty reference class: the current Paint Mountain build, ordinary physics-
  puzzle difficulty answers, and the complete candidate set produced here.
- Requested candidate or round count: not specified; use four rounds of three
  candidates while structurally new families remain.

### User request

> Raise this game's difficulty through staged ideas, expand exploration beyond
> similar games into apparently unrelated fields, compare multiple hypotheses,
> select one, write a plan, document the intermediate process in English, and
> create an easy Korean Markdown explanation of the final decision.

### Search contract

- Facts supplied by the user: broad cross-domain exploration, comparative
  selection, English intermediate documentation, and a Korean final explainer
  are required.
- Hard constraints: preserve the effective source brief; all stages remain open;
  the cannon stays fixed; the player chooses the launch and never steers in
  flight; visual paint and coverage share one authoritative mask; exactly three
  mechanism types remain; no new production dependency or online system.
- Provisional criteria: planning depth, learnability, causal clarity,
  deterministic retry value, architectural fit, restrained UI, testability,
  and gradual thirty-stage progression.
- Inherited assumptions that may be challenged: later difficulty must come from
  larger terrain, higher target coverage, more mechanisms, less time, or more
  precision.
- Available resources: baked stage catalog, typed stage/generation Resources,
  attempt and shot observations, local best results, current tests, official
  external sources, and read-only exploratory agents.
- Material unknowns: which difficulty family produces the strongest planning
  value; what new persisted state is justified; which playtest thresholds can
  be locked without current player data.

### Pre-research baseline

- Common frames likely to appear: smaller targets, stricter timers, fewer shots,
  stronger wind, more obstacles, more mechanisms, less trajectory help, moving
  targets, locked stages, and adaptive enemy-style rubber-banding.
- Initial hypotheses worth checking: difficulty as terrain complexity;
  difficulty as information reduction; difficulty as multi-objective scoring;
  difficulty as a staged experiment protocol; difficulty as a self-selected
  challenge contract; difficulty as recovery from partial failure.
- A broader answer should add: mechanisms from learning science, assessment,
  sports course setting, safety training, control theory, ecology, or other
  distant systems without importing their surface form.

## Limitations

- This file defines the search boundary and does not select a candidate.
