현재 UI는 구현 기준을 충족한다

중복 공 설명, 흰색 queue 박스, 잘린 점수축, 좌측의 고립된 시점 버튼, 중앙 Shot Follow 버튼, compact 상단 충돌을 제거했다. UI는 terrain 위에 직접 놓이고, 필요한 순간에만 짧은 글과 벡터 아이콘을 쓴다.

마지막 Web 발견도 수정했다. Stage Select 규칙 줄의 유니코드 기호가 Web에서 네모로 깨지던 문제를 없애고, Ball Queue와 같은 공유 벡터 공 아이콘을 사용한다.

주요 화면

Stage Select

지형이 선택의 중심

실제 준비된 terrain을 크게 유지한다. 아래 한 줄은 목표 범위, R/G 가중치, 탄 수, 필수 특수 공만 보여준다. 폰트 기호가 아니라 공유 벡터 glyph라 Windows/Web에서 동일하다.

Aim

C안 · 대포 중심

대포와 탄도가 중앙 하단에서 산으로 이어진다. 수직 점수축은 왼쪽 안전영역에서 0과 100을 모두 보여주며, angle–Fire–power는 한 줄이다.

Ball Queue

hover·focus·press가 같은 설명

공 자체가 hit target이다. 현재 공과 다음 공을 shape + R/G로 구분하고, 설명은 queue 바로 아래 한 곳에만 나타난다. native tooltip은 꺼서 메시지가 두 번 뜨지 않는다.

640×360에서도 같은 정보 구조

작은 화면은 요소를 임의로 축소하지 않는다. 공유 density preset이 글꼴, 아이콘, 간격, hit target을 같이 키우고 재배치한다.
