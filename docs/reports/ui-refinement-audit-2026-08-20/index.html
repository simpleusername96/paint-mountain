P1

compact readable-size 기준 추가

Stage Select의 규칙, Result의 contribution, Settings의 다음 그룹이 640×360에서 지나치게 작거나 fold 아래로 밀린다. 단순 scale-down이 아니라 compact typography와 정보 우선순위를 shared preset으로 둔다.

P2

Pause 밀도와 뒤쪽 Gear 정리

단일 interruption surface 사용은 맞지만 내용보다 높고, 동일한 Gear가 dim layer 뒤에 남는다. surface 높이는 내용에 맞추고 modal 동안 배경 Gear를 숨긴다.

접근성 판단

화면에서 확인된 것

  • Red/Green queue는 색과 R/G 문자, 공 종류 shape를 함께 사용한다.
  • signed score underflow는 숫자와 rail endpoint shape를 함께 사용한다.
  • filled Blue는 대부분 한 화면의 primary action 하나에만 사용된다.
  • 640×360에서도 주요 action과 0–100 endpoint 자체는 화면 밖으로 잘리지 않는다.

화면만으로 확인할 수 없는 것

  • keyboard focus 순서와 focus-visible, Ball Queue의 hover/focus/press 동등성, Settings scroll-follow.
  • icon-only Gear와 mode control의 accessible name, live score update의 전달 방식.
  • 실제 contrast ratio, pointer target 크기, 200% text scaling, reduced motion.

따라서 이 보고서는 WCAG 준수 판정이 아니다. W3C의 “색만으로 정보를 전달하지 않는다”는 원칙을 game HUD에 방향성 있게 적용했다.

비교 레퍼런스와 적용 범위

Lonely Mountains: Downhillworld가 주인공인 작은 direct HUD. Paint Mountain의 menu와 live HUD 점유율 판단에만 적용.
art of rallydashboard surface 없이 배치한 얇은 instrument. ScoreScale과 edge status의 restraint에 적용.
Nintendo Switch Sports Golf끝점과 tick이 완전한 power scale. 0–100 ScoreScale이 target band 때문에 잘리지 않는 기준에 적용.
Monument Valley · Level Select정보 카드 그리드보다 level 자체를 탐색 대상으로 보여 주는 방식. 실제 terrain Stage Select에 적용.

위 레퍼런스의 layout·art를 복제하지 않았다. 낮은 UI 점유, 완전한 scale, icon/value grouping, stage-as-world만 현재 승인된 Quiet Context와 Cannon Focus 방향에 대조했다.

증거 한계

이번 16장은 같은 audit run에서 새로 생성하고 원본 크기로 열어 확인했다. 잘못된 창, loading, blank, sub-region crop은 없었다. deterministic result capture는 실제 terminal transition 뒤 표시 값을 고정해 layout을 검증하므로 물리 clear 증거가 아니다. 실제 조작감, hover 지연, 키보드 경로, 화면 읽기 도구, paint latency는 별도 실행 검증이 필요하다.
