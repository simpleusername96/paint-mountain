Paint Mountain · Screen Audit · 2026-08-10

화면별 UX·비주얼 감사와 개선 시안

현재 Windows 릴리스의 실제 화면 10개를 캡처해 분석하고, Quiet Context 스타일을 유지한 개선안을 만들었습니다. 이후 불필요한 메타 텍스트·중복 단축키·장식용 얇은 선을 걷어내는 피드백을 반영해 핵심 7개 화면을 다시 다듬었습니다.

기준 화면 1280×720 대표 검증 1920×1080 한국어 기본 실제 릴리스 캡처 개선 시안 10종 피드백 정제 7종

종합 판정

구조와 기능은 안정적이지만, 몇몇 화면은 플레이 대상보다 빈 공간이나 UI가 더 강하게 보입니다.

현재 구현: 개선 필요
잘 된 점일관된 색·서체, 한 개의 명확한 주 행동, 실제 기능만 노출
가장 큰 문제지도 보기의 지나치게 작은 산과 큰 빈 공간
반복 문제중앙 가림, 과도한 설명, 중복 단축키, 장식용 얇은 선
개선 원칙세계를 키우고, 필요한 정보만 남기며, 경계는 의미가 있을 때만 사용
우선순위대상문제권장 조치
높음지도 보기산이 화면 중앙의 작은 섬처럼 보여 지형 조사 목적을 약화함안전 여백 안에서 산을 2배 이상 키우고, 중심 표식을 산과 함께 읽히게 배치
높음브리핑·탄환 추적중앙 패널 또는 복귀 버튼이 관찰해야 할 지형과 물리 장면을 가림오버레이를 모서리 안전 영역으로 이동하고 중앙은 세계에 양보
높음스테이지 선택카드 텍스트가 경계에 가까우며 시작 버튼이 지나치게 넓음번호·이름·기록을 2단 계층으로 나누고, CTA를 내용 폭에 맞춤
중간메뉴·결과1920×1080에서 버튼과 빈 공간이 커지고 산의 존재감은 상대적으로 약해짐최대 폭을 두고 세계 프리뷰·결과 산의 화면 점유율을 유지
중간설정얇은 슬라이더와 작은 토글이 조작 상태를 약하게 전달클릭 영역을 넓히고 켜짐/꺼짐을 텍스트·형태로 함께 표시

중요: 오른쪽 이미지는 구현 완료 화면이 아니라, 현재 화면을 기준으로 만든 개선 개념입니다. 실제 3D 지형·물리·정확한 한국어 렌더·키보드 동작을 증명하지 않습니다.

피드백 반영 기준

스타일은 유지하고, 화면의 역할과 직접 관계없는 설명만 제거했습니다.

v2 기준 확정
구분화면에 남김일반 화면에서 제거
텍스트화면·스테이지·모드 이름, 실제 수치, 실제 행동, 종료 사유, 오류·로딩홍보 문구, 전략 설명, 반복 목표 문장, 자동 저장·언어 도움말, 결과 계산 설명
학습현재 모드에 맞는 하단 조작 가이드 한 줄버튼 안의 Space/F/Tab, 별도 마우스 힌트, 곳곳에 반복되는 튜토리얼 문장
브리핑스테이지 정체성, 지형 확인 모드, 실제 지형 문양, 뒤로·조준 시작목표 설명 패널, 지형 위 장치 이름, 중복 지형 확인 문장
선·경계초점, 선택, 입력 컨트롤, 진행 레일, 목표 표식, 모달 외곽전체 폭 구분선, 열 구분선, 결과 내부 선, 선택되지 않은 카드의 반복 테두리
설명 위치향후 가이드북, 최초 튜토리얼, 전용 UI 가이드매번 보는 메뉴·브리핑·설정·결과 화면

보존 원칙: 접근성 이름, 툴팁, 오류·로딩·비활성 사유, 스테이지 목표와 장치 설명의 원문 데이터는 삭제 대상이 아닙니다. 화면에서 숨긴 설명은 향후 학습 표면에서 재사용할 수 있게 남깁니다.

최종 시안을 실제 Godot 화면으로 옮기기 위한 파일별 책임, 수치 기준, 테스트, 캡처, 재작업 조건은 상세 구현 계획문서에 정리했습니다.

01메인 메뉴

첫 진입에서 게임의 성격과 시작 행동을 전달하는 화면

보통 · 개선 권장

강점

게임 제목과 실제 행동 목록이 분명하고, 플레이만 파란 주 행동으로 처리한 위계가 좋습니다.

문제

영문 눈썹 문구와 한국어 태그라인은 다음 행동을 고르는 데 필요하지 않습니다. 넓은 버튼 열과 반복 경계는 산 프리뷰보다 먼저 보입니다.

개선

제목과 네 가지 실제 행동만 남기고 메뉴 폭을 제한합니다. 보조 행동은 조용하게 처리하며, 산 프리뷰의 대비·크기를 높여 빈 공간을 게임의 물성으로 채웁니다.

02스테이지 선택

30개 산 중 하나를 비교하고 시작하는 화면

주의 · 우선 개선

강점

선택 목록과 상세 설명이 분리되어 있고, 선택 상태는 색과 테두리로 드러납니다.

문제

목표 문장이 선택 목록과 상세 영역에서 반복되고, 모든 카드 테두리와 중앙 구분선이 정보보다 강합니다. 시작 버튼도 상세 영역 전체 폭을 차지해 필요 이상으로 무겁습니다.

개선

카드에는 번호·이름·목표 수치·기록만 남기고 전략 문장은 뺍니다. 선택된 카드만 파란 외곽선을 사용하고, 나머지는 부드러운 면과 여백으로 묶습니다. 시작 버튼은 내용 폭에 맞춥니다.

03브리핑

지형과 장치를 살핀 뒤 조준으로 넘어가는 화면

주의 · 우선 개선

강점

지형을 둘러보고 조준으로 넘어간다는 상태 전환 자체는 명확하며, 실제 문양의 색과 형태가 장치 존재를 전달합니다.

문제

산이 작고 중앙 목표 패널이 지형을 가립니다. 문양 위의 장치 이름과 별도 마우스 힌트는 하단 가이드와 역할이 겹칩니다.

개선

산을 크게 프레이밍하고 목표 문장을 제거합니다. 좌상단에는 스테이지와 지형 확인 상태만, 좌하단에는 뒤로·조준 시작만 둡니다. 지형에는 이름 없는 실제 문양만 남깁니다.

04조준 보기

목표점을 정하고 각도·파워를 조정한 뒤 발사하는 핵심 화면

양호 · 미세 조정

강점

산과 궤적이 중심이고, 발사가 유일한 파란 주 행동입니다. 각도·파워와 하단 맥락 안내도 실제 조작에 맞습니다. 1920×1080에서도 겹침은 보이지 않습니다.

문제

발사 옆 Space, 완료 옆 F, 보기 전환 옆 Tab이 하단 가이드와 중복됩니다. 하단 전체 폭 선과 파워 내부 구분선도 조작 이해에 기여하지 않습니다.

개선

실제 버튼에는 발사·완료·조준/지도 보기처럼 행동 이름만 남깁니다. 단축키는 하단 가이드가 단독으로 소유하고, 장식 선은 제거하되 입력 레일·초점·진행 표식은 유지합니다.

05지도 보기

산의 전체 구조를 회전·확대해 조사하는 화면

주의 · 최우선 개선

강점

발사와 조준 조작이 숨겨져 관찰 모드임은 분명합니다. 하단 문구도 드래그·휠·Tab·Esc만 보여줍니다.

문제

산이 화면의 약 20% 정도로 축소되어 경로와 장치 위치를 읽기 어렵습니다. 커다란 빈 공간이 조사 작업의 초점을 약화합니다.

개선

산을 중앙 작업 영역의 55–65%까지 확대합니다. 좌측 상태와 상단 메뉴의 안전 여백만 남기고, 초점 표식은 지형과 함께 읽히게 합니다.

06탄환 추적

발사한 공과 첫 접촉·페인트 결과를 관찰하는 화면

주의 · 우선 개선

강점

조준 컨트롤이 사라지고 공이 크게 보이므로 상태 전환은 이해하기 쉽습니다. 복귀 행동도 명시되어 있습니다.

문제

복귀 버튼이 화면 중앙에 떠 있어 공의 그림자와 접촉 지형을 가립니다. 핵심 원인-결과 장면과 직접 경쟁합니다.

개선

복귀 행동을 좌상단 또는 좌하단 안전 영역으로 이동합니다. 중앙에는 공, 접촉, 페인트만 남기고 하단 문구는 보조 수단으로 유지합니다.

07일시정지

플레이 입력을 막고 다음 내비게이션을 선택하는 화면

양호 · 미세 조정

강점

한 개 모달, 분명한 계속 행동, 올바른 메뉴 순서가 안정적입니다. 배경이 어두워져 입력 차단 상태도 읽힙니다.

문제

보조 행은 텍스트만 떠 있는 느낌이고 실제 클릭 영역을 시각적으로 추정하기 어렵습니다. 배경의 Gear도 약하게나마 조작 가능한 것처럼 보입니다.

개선

각 행의 높이와 경계를 더 일관되게 보여주고, 배경 조작 요소는 더 확실히 비활성화합니다. 계속의 파란 초점은 유지합니다.

08설정

오디오·게임플레이·화면·언어를 조정하는 화면

보통 · 접근성 보강

강점

두 열 구성이 논리적이며 화면·언어 선택은 자연스럽습니다. 설정 안에 다시 시작을 넣지 않은 흐름도 올바릅니다.

문제

자동 저장과 언어 적용 도움말은 설정값이 아니며 매번 볼 필요가 없습니다. 중앙 열 구분선과 각 토글 행의 반복 외곽선도 화면을 잘게 나눕니다.

개선

실제 설정과 값만 남깁니다. 두 열은 간격과 제목 정렬로 구분하고, 토글 행은 테두리 없는 클릭 영역으로 처리합니다. 스위치 트랙과 슬라이더처럼 조작에 필요한 경계는 굵고 분명하게 유지합니다.

09직접 종료 결과

플레이어가 완료를 선택해 현재 도색 결과를 확정한 상태

보통 · 위계 개선

강점

도색률, 등급, 이전 최고, 시간과 사용 탄 수가 한 패널에 모여 있습니다. 재도전이 주 행동인 점도 명확합니다.

문제

‘최종 목표 영역’과 계산 설명은 큰 도색률 수치가 이미 전달하는 내용을 반복합니다. 넓은 패널과 같은 무게의 세 버튼은 산과 다음 행동의 위계를 약하게 만듭니다.

개선

완료, 큰 도색률, 짧은 목표 수치, 등급·최고·시간·탄 수만 남깁니다. 재도전만 파란 버튼으로 유지하고 다음은 보조, 스테이지 선택은 텍스트 행동으로 낮춥니다.

10시간 종료 결과

제한 시간이 끝나 현재 도색 결과가 확정된 상태

보통 · 상태 구분 개선

강점

제목이 직접 종료 결과와 다르며, 최종 파란 페인트 경로가 세계에 남아 있습니다.

문제

종료 사유의 차이는 제목 한 줄에 거의 전부 의존하면서, 반복 설명은 직접 종료 화면과 같은 밀도를 만듭니다.

개선

시계 형태와 제목을 함께 사용해 시간 종료를 표시하고, 나머지는 큰 도색률·목표·기록·행동만 남깁니다. 내부 장식 선 없이 직접 종료 결과와 같은 정보 위계를 유지합니다.

접근성·상태 검토

스크린샷에서 확인할 수 있는 범위와 확인하지 못한 범위를 분리했습니다.

정적 화면 기준
항목확인 결과한계
한국어 맞춤1280×720과 대표 1920×1080에서 잘림은 보이지 않음. 스테이지 카드는 여백이 부족함.더 긴 번역 문자열과 200% 텍스트 확대는 미검증.
초점 표시주 행동에 2px 수준의 파란 초점/외곽선이 보임.전체 키보드 이동 순서와 초점 복원은 스크린샷만으로 확인 불가.
색 이외의 상태장치 문양은 색과 형태를 함께 사용. 시간 종료 개선안도 시계 형태를 병행.현재 토글과 일부 선택 상태는 색·위치 의존이 큼.
대비남색 본문과 파란 주 행동은 대체로 읽힘.회색 도움말, 비활성 완료, 밝은 지형 면은 수치 측정하지 않음.
대상 크기주 버튼은 충분히 큼.슬라이더 손잡이, 작은 토글, Gear의 실제 키보드 이름과 클릭 영역은 정적 화면만으로 확정 불가.
모션·입력 차단일시정지 스크림과 탄환 추적 전용 상태가 시각적으로 구분됨.감소된 모션, 입력 누출, 실시간 상태 알림은 실행 상호작용 테스트가 필요.
