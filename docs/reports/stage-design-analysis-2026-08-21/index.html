현재 설계는 “릴리스 가능한 규칙 구조”다

이전 5패턴 반복과 색상 0점 규칙을 제거했다. Stage 07 이후 두 색이 모두 점수 계산에 들어가며, 두 색의 실제 target paint와 stage별 필수 Burst/Split 기여가 clear 조건이다. 지형, rule, target mask, deal 중 하나라도 바뀌면 v13 certificate seal이 깨진다.

다만 certificate는 가능한 score 조합과 deal cover를 증명하지, 재미있는 조준 해법·실패율·학습 곡선을 증명하지 않는다. 그래서 “달성 불가능한 데이터”는 자동 차단하지만 “재미있다”는 결론은 내리지 않는다.

진행 설계 판단

Stage 01–06

학습 구간 보존

기존 target band, 탄 수, deal 계약을 그대로 보존했다. v12→v13 migration test가 world/layout/score/deal identity를 비교한다.

Stage 07–12

색과 특수 공을 clear 조건으로 진입

양수 조합으로 넓게 칠하기를 먼저 익히고, Green 우선·Red 우선 감점 규칙으로 넘어간다. Burst/Split 요구를 stage마다 달리한다.

Stage 13–18

route control

세 route와 7-shot 구간에서 같은 공을 어디에 쓸지 압축한다. Chapter end는 두 특수 공의 target 기여를 모두 요구한다.

Stage 19–24

mechanism selection

5개 mechanism을 무조건 전부 밟는 것이 아니라, 점수 부호와 target band에 맞는 route를 선택하게 한다.

Stage 25–30

full-system mastery

양 색 회복과 단색 우선 규칙을 번갈아 쓰고, 마지막 네 stage는 Burst와 Split의 실제 target paint를 모두 요구한다.
